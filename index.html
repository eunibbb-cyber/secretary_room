⚙️ 연결 설정

실시간 서버(Supabase)와 연결합니다. 새 글을 3초마다 확인하고, 화면으로 돌아오면 바로 동기화합니다.

브라우저 공개용 키입니다(비밀 키 아님). 이 키로 messages·tasks·memos를 읽고 씁니다.

앱을 열면 서버에서 대화·작업·메모를 불러오고, 새 글은 3초마다 확인합니다. 끊기면 상단에 연결 끊김만 표시합니다.

열쇠는 이 브라우저에만 저장됩니다. 코드·공개 저장소에는 절대 넣지 마세요.

셋톡이 브라우저 직접 호출(CORS)을 막으면 “연결 실패”로 표시됩니다. 그때는 직접 URL(프록시)을 쓰세요.

GET /messages?since=ID → { messages:[{id, who, text, ts, owner}] }
POST /messages ← { who, text }

로컬 모드에서만 쓰입니다. 실시간 서버 모드에서는 켜져 있어도 동작하지 않고, 실제 비서들이 서버에 답장을 답니다.
